## 3. Implementation Overview

### Part A: Hack Computer (`CPU.hdl`, `Memory.hdl`, `Computer.hdl`)
- **`CPU.hdl`**: Integrates `ARegister`, `DRegister`, `ALU`, and `PC`. Decodes `instruction[15]` to distinguish A-instructions (`0`) from C-instructions (`1`), routes `d1..d3` destination bits, `c1..c6` ALU control bits, `a` (`instruction[12]`) A/M selection, and `j1..j3` jump conditions (`ng`, `zr`, `pos`).
- **`Memory.hdl`**: Decodes `address[13..14]` using `DMux4Way` and `Mux4Way16` across `RAM16K` (`0..16383`), `Screen` (`16384..24575`), and `Keyboard` (`24576`).
- **`Computer.hdl`**: Connects `ROM32K`, `CPU`, and `Memory` with `reset` propagation.

### Part B: Two-Pass Hack Assembler (`assembler.py`)
- **Pass 1:** Strips `//` comments and whitespace, tracks original source line numbers, records label ROM addresses without incrementing the instruction counter, and implements **Case 2 ($98 \bmod 3 = 2$)**: prints `Warning: duplicate label <NAME> at line <N>` to `stderr` without overwriting the first definition.
- **Pass 2:** Encodes A-instructions (constants `0..32767`, predefined symbols `SP`, `LCL`, `ARG`, `THIS`, `THAT`, `R0..R15`, `SCREEN`, `KBD`, labels, and variables starting at RAM `16`) and C-instructions (`111` + `comp` + `dest` + `jump`) using validated lookup tables (no `eval()`).

### Part C: Interactive Box Program (`Box.asm`, `Box.hack`)
- Continuously polls `KBD` (`RAM[24576]`) in `MAIN_LOOP`.
- When any key is pressed (`KBD != 0`), fills `20` rows $\times$ `3` words/row starting at `19520` (`SCREEN + 32 * 98`) with `-1` (`0xFFFF`, black).
- When released (`KBD == 0`), fills the exact same `60` words with `0` (`0x0000`, white).

## 4. How to Run & Verify

### Run Python Assembler & Automated Tests
```powershell
python capstone\assembler.py capstone\Box.asm capstone\Box.hack
python capstone\tests\test_assembler.py -v
python capstone\tests\test_box_simulation.py -v
```

### Compare Against Official Nand2Tetris Assembler
```powershell
python capstone\tests\compare_outputs.py --asm-dir "<path-to-nand2tetris>\projects\06" --official-assembler "<path-to-nand2tetris>\tools\Assembler.bat"
```

### Run Official HDL Tests (Hardware Simulator)
Open `<path-to-nand2tetris>\tools\HardwareSimulator.bat` (or run CLI) and execute:
1. `CPU.tst`
2. `Memory.tst`
3. `ComputerAdd.tst`
4. `ComputerMax.tst`
5. `ComputerRect.tst`

Save screenshots in `capstone/evidence/` as `CPU_test.png`, `Memory_test.png`, `ComputerAdd_test.png`, `ComputerMax_test.png`, and `ComputerRect_test.png`.

### Run `Box.hack` (CPU Emulator)
1. Open `<path-to-nand2tetris>\tools\CPUEmulator.bat`.
2. Load `capstone\Box.hack`.
3. Set animation to **No animation**, click **Run**, press and hold any key to display the `48 x 20` box at row `98`, release the key to clear it, and save a screenshot as `capstone/evidence/Box_output.png`.
